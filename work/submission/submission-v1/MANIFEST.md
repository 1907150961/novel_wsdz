## 全局整改规则（所有章节统一执行）

1. **格式硬伤清零**：删除所有 Markdown 反引号、`【】`场景标记、工作批注式语句；人物书写内容（备忘录、屏幕文字、文件封面）改为正文叙述或引号文本，不残留任何符号。
2. **AI痕迹收敛**：破折号密度控制在每千字≤3处；"不是…是…"句式每章≤4次且仅限陆沉视角；时间标签避免机械罗列（单章同一时间词不超5次，优先用事件承接代替"晚上/凌晨"反复标注）；否定句式密度收敛，改写重复的心理总结与抽象判断。
3. **字数补足**：每章目标8000字左右（CJK）。在不新增剧情节点、不改变场景结构与冻结接口的前提下，通过场景细节、动作链、对话停顿、感官描写扩充；禁止注水（重复回忆、同义对话、空泛环境）。
4. **保留**：所有剧情事实、人物认知边界、证据链、章末牵引、伏笔状态。
