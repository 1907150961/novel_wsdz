## 一、旁白替读者解释人物潜台词（检查项2）

---

### AI-01：第1章——叙事者替服务员和"后来的周砚"完成解读

**文件**：第1章，第125-126行
**等级**：🔴 必须修改

**原文**：
> "他转身往后厨走的时候，嘴角动了一下。不是笑——嘴唇只是向一侧牵了不到一厘米，然后恢复了原状。那个画面后来被周砚从监控里截下来反复播放。每一次他都觉得那是一个字被咽回去的形状，但他说不出来是哪个字。"

**判断理由**：

三处旁白越界：
1. "后来被周砚从监控里截下来反复播放"——叙事者在第一现场就预告了这个细节的后续调查价值。读者无需通过周砚的视角自己去发现。
2. "每一次他都觉得那是一个字被咽回去的形状"——这是周砚的主观感受。叙事者无权在周砚出场的场景之外以全知口吻替他做判断。
3. "但他说不出来是哪个字"——连周砚的困惑都被叙事者提前揭晓。

这属于 `avoid-patterns.md` 第一条"提前替读者解释钩子"。`rejected/01` 已将此处收录为反例。

**是否必须修改**：是。这是全书第一章的尾钩，先于周砚的发现把悬疑卸掉。

**最小修改方向**：

```
他转身往后厨走的时候，嘴角动了一下。嘴唇向一侧牵了不到一厘米，然后恢复了原状。

// 句号收束。留给周砚，留给读者。
```

### AI-02：第1章——叙事者替全场人群做集体心理分析

**文件**：第1章，第119行
**等级**：🟡 建议修改

**原文**：
> "落地的声音在宴会厅里听不到。但所有人都知道那一下有多重。他们只是没有看到，所以觉得这件事像是在电视上发生的。和他们隔着屏幕，隔着距离，隔着'我只是在场而已'的说辞。"

**判断理由**：

前三句有效——"听不到""知道有多重""像在电视上发生的"是现场众人的真实状态描述。但最后一句"隔着屏幕，隔着距离，隔着'我只是在场而已'的说辞"是叙事者在替两百多个互不相识的人统一下结论——两百多人不会共享同一种自我辩护措辞。叙事者替他们说出来，读者就被剥夺了"自己去感受这群人如何为自己找借口"的空间。

**是否必须修改**：否。现场感仍然成立。建议将"隔着'我只是在场而已'的说辞"删去，保留前三句的无解释状态。

**最小修改方向**：

```
落地的声音在宴会厅里听不到。但所有人都知道那一下有多重。他们只是没有看到，所以觉得这件事像是在电视上发生的。
```

## 二、动作后追加解释（检查项1+5统合）

---

### AI-03：第4章——同一含义用四句话重复

**文件**：第4章，第131行
**等级**：🔴 必须修改

**原文**：
> "不是删。只是关了。关了和删了不一样。他告诉自己关了和删了不一样。"

**判断理由**：

四句话全部在说同一件事：
1. "不是删"——否定
2. "只是关了"——确认
3. "关了和删了不一样"——解释
4. "他告诉自己关了和删了不一样"——再次确认（"他告诉自己"是冗余的元叙事）

属于检查项14"同一含义用多个句子重复表达"的典型样本。前文第4行已经用陆沉在帖子上空犹豫停留的动作充分建立了这个心理矛盾，不需要再用四句话循环解释。

**是否必须修改**：是。四句→一句。

**最小修改方向**：

```
光标在帖子上空停了一会儿，然后他点了关闭标签页。
```

读者的理解："他不删帖，只是关掉——他需要假装自己什么都没做。"

### AI-04：第5章——动作已到位，用长句补了两层解释

**文件**：第5章，第95行
**等级**：🟡 建议修改

**原文**：
> "他关了邮件。没有去接水。上一次他接水去了。这一次他坐着没动。不是因为不害怕。是因为害怕的方式变了——上一次是害怕被发现，这一次是害怕自己不再是唯一能控制这件事的人。"

**判断理由**：

"他关了邮件。没有去接水。"——读者从第2-4章已记住"接水"是陆沉的紧张替位动作。"没有去接水"意味着这个紧张已经超出了他习惯的排解范围。这个动作本身已经完成了所有需要传达的信息。

后面的"不是因为不害怕。是因为害怕的方式变了——"是叙事者替已经到位的动作做课后注释。

属于检查项1"先用动作表现情绪，随后又解释一次情绪"。

**是否必须修改**：否。但"上一次是害怕被发现，这一次是害怕自己不再是唯一能控制这件事的人"是典型的AI式自我总结——将人物内心精确地框在两个可选项里，不给理解留下缝隙。

**最小修改方向**：

```
他关了邮件。没有去接水。上一次他接水去了。这一次他坐着没动。
```

## 三、"不是……是……"过度使用（检查项5）

---

### AI-05：第4章第132-137行——"不是因为……是因为……"密集出现

**文件**：第4章，第132-137行
**等级**：🟡 建议修改

**原文**（连续出现的"不是/因为"结构，已标出）：
> "他意识到自己在出汗。**不是因为**热——空调开着。**是因为**从关门到现在他一直在做同一件事：把曹老板从数据里推出去。"
>
> "他失败了。"
>
> "**不是因为**数据不够干净。**是因为**五金店老板那句'我喝了他八年茶没喝死'卡在数据库和笔记之间。"

**判断理由**：

四行内出现两次"不是因为……是因为……"，且被一个"他失败了"隔开，形成解释-停顿-再解释的节奏。"他失败了"三个字本身是好的留白——叙事停止、让判断悬置——但下一行立刻又用"不是因为……是因为……"把"失败"的原因拆开。

属于 `avoid-patterns.md` 第五条。`target-style.md` 规定陆沉视角每章≤4次，此处在30行内出现两次，超出了情感密度需要的频率。

**是否必须修改**：否。两处均可单独保留，但建议删去其中一处。保留"不是因为热——空调开着。是因为从关门到现在……"，删去"不是因为数据不够干净。是因为……"——该句的信息已包含在前文。

### AI-06：第3-4-5章——"不是……是……"在叙事者描写中出现（非陆沉视角）

**文件**：第3章第123行、第4章第139行
**等级**：🟢 可保留

**原文**：

第3章第123行：
> "那不是拥抱。是借力——她的左腿睡麻了，需要扶一下东西才能站稳。"

第4章第139行：
> "把'机制'选中，按退格，打了两个字——'现象'。然后看着新标题——'现象观察笔记'。够中性。够不承诺任何立场。"

**判断理由**：

第3章"那不是拥抱。是借力"是陆沉的观察——他当时在场（躲在她身后），这是他的主观判断。第4章"够中性。够不承诺任何立场"也是陆沉的内心独白。这两处符合 `target-style.md` 的规定：属于陆沉视角，是人物标志性声音。

但需警惕："够中性。够不承诺任何立场"是两个极短判断句连续——这种以句号隔断的短判断在陆沉视角中如果高频出现（每页>2次），会从"克制"变成"叙事者在替人物做态度标注"。

**是否必须修改**：否。当前频率可接受。

## 四、段落后附结论（检查项9）

---

### AI-07：第4章——观察段落完毕后追加一句社会评论

**文件**：第4章，第129行
**等级**：🟡 建议修改

**原文**：
> "一个开了十年的店，没有任何官方记录说它的茶有问题——也没有任何官方记录说它的茶没问题。曹老板活在一个灰色的夹层里，他的清白和罪名都不需要证据。"

**判断理由**：

前半句是陆沉的搜索结果（数据事实）。后半句"曹老板活在一个灰色的夹层里，他的清白和罪名都不需要证据"是叙事者替陆沉（也是替读者）把这个事实抽象为一句社会评论。

属于检查项9"每段末尾都补充结论"。这段的情节驱动是陆沉"想确认自己是否害了无辜者但无法确认"——这个矛盾已经足够。把他无法确认的困境提炼成"他的清白和罪名都不需要证据"削弱了困境的不确定感——因为叙事者用一句完整结论替不确定画了句号。

**是否必须修改**：否。社会评论与此书主题契合，保留或删除皆可。但全书若每个类似的观察段落都配一句社会评论，将形成可预测的"观察→结论"节奏。

**最小修改方向**：

```
一个开了十年的店，没有任何官方记录说它的茶有问题——也没有任何官方记录说它的茶没问题。
// 删除最后一句。让搜索结果自身的不确定性悬置在读者心里。
```

### AI-08：第5章——叙事者的"系统"论断取代读者理解

**文件**：第5章，第85行
**等级**：🟡 建议修改

**原文**：
> "系统不是为了让好东西流传设计的，系统是为了让东西不消失设计的。它不在乎你放进去的是向日葵还是凋谢的花，它只在乎你有没有填对表格。审核是外包的，只看格式不看内容。续约是自动的，没人回就默认同意。从设计到投放再到续约——他参与了第一步，然后每一步都是系统在替他走。"

**判断理由**：

这一段的前半句是对系统运作的陈述（审核外包、只看格式、续约自动），是陆沉和读者共享的事实。但"系统不是为了让好东西流传设计的，系统是为了让东西不消失设计的"——这句是叙事者以警句口吻在替小说提炼主题。它不像陆沉会说的话（陆沉不会用"好东西"这种模糊词），也不像是纯粹的叙事——它是旁白在告诉读者"你应该从这个角度理解前面的情节"。

属于检查项2和9的交叉：旁白替读者解释+段落后附结论。

**是否必须修改**：否。"他参与了第一步，然后每一步都是系统在替他走"扣住了陆沉的心理，这个收束可以保留。但开头的警句"系统不是为了让好东西流传设计的，系统是为了让东西不消失设计的"建议压缩或删除——让读者自己从"审核只看格式""续约默认沿用"两个事实中推导，而不是提供一个预制的解释框架。

### AI-10：第3章与第4章尾钩使用同一视觉模式

**文件**：第3章第135行、第4章第217-219行
**等级**：🟡 建议修改

**原文**：

第3章章末：
> "他没想好标题。他只是把光标放在那里。一闪。一闪。一闪。"

第4章章末：
> "他打开了一个新的设计文件。光标停在白色画布中央。他没有立刻动笔。他只是把光标放在那里，像把手指放在脉搏上。一闪。一闪。"

**判断理由**：

两章的章末钩子使用完全相同的意象（光标在空白画布上闪）。第3章的"一闪。一闪。一闪。"有力量——三连极短句让停顿本身成为节奏事件。第4章再次使用时，虽然加了"像把手指放在脉搏上"的比喻来制造差异，但读者不会读到比喻——读者读到的是"光标在空白处闪"的视觉重复。

属于 `avoid-patterns.md` 第八条。`target-style.md` 规定"同一视觉意象不作为连续两章的尾钩"。

**是否必须修改**：是。两章尾钩其一需更换意象。

**最小修改方向**：保留第3章的尾钩（它是能力觉醒后的第一次停格，功能不可替代）。第4章尾钩换用其他意象——第4章结尾陆沉"知道自己在画谁的脸"这个认知比视觉意象更重要。可以考虑删除"光标闪"的描写，直接以"这一次，他知道自己在画谁的脸"收束。

## 六、节奏过于平均，连续段落承担相似功能（检查项13）

---

### AI-11：第4章第126-143行——连续六段遵循"动作→内省→结论"模式

**文件**：第4章，第127-143行
**等级**：🟡 建议修改

**原文段落功能分解**（从"陆沉说了声谢谢"到"不确定变量"）：

| 段落 | 功能 |
|------|------|
| L127 | 动作（走回公交站+拧瓶盖）→ 结论（"他等的不是公交"） |
| L129 | 动作（搜索检测报告/投诉）→ 结论（"清白和罪名都不需要证据"） |
| L131 | 动作（开后台/关标签页）→ 结论（"关了和删了不一样"×4次） |
| L133-135 | 动作（改文件名/出汗）→ 结论（"把曹老板从数据里推出去"）→ 短句收束（"他失败了"） |
| L137 | 结论（"不是因为数据不够干净。是因为……"）→ 动作（加了一段笔记） |
| L139-143 | 动作（打字/删改/关文档/接水）→ 结论隐含（"不确定变量"） |

**判断理由**：

六段中有五段遵循"具体动作→抽象结论"的同一结构，且每个结论都是一句完整的社会/心理判断。读者在这段阅读中的体验是：看到动作→被给一个结论→下一个动作→下一个结论→...节奏缺乏变化。

段落 L139-143 是最接近理想的一段——动作密集、结论不直接说出（"不确定变量"保留悬置）。但前面的段落已经让读者"吃饱了结论"。

**是否必须修改**：否。但建议从六段中选择1-2段删除结尾结论句（如 L127 的"他等的不是公交。...他等的是自己下一个想法"和 L129 的"清白和罪名都不需要证据"），让动作自己承担叙事。剩余的结论段落之间的张力反而会被强化。

## 七、环境描写与人物注意力无关 / 所有信息都被解释清楚（检查项11+12）

---

### AI-12：第1章——实习记者段落的"不是因为恐惧。是因为她想站第二次，但站不起来了"

**文件**：第1章，第113行
**等级**：🟢 可保留

**原文**：
> "她坐回去之后，发现自己一直在发抖。不是因为恐惧。是因为她想站第二次，但站不起来了。"

**判断理由**：

"不是因为恐惧。是因为她想站第二次，但站不起来了"——这属于检查项1（动作后追加解释）。但此处的人物不是陆沉，叙事者为何能确认她发抖的原因？

然而这是有效的：实习记者的发抖和她无法第二次站起的无力感，是"全员沉默"主题的第一个具体样本。叙事者在此处的解释比任何旁观描写都更经济地完成了这个人物在叙事中的功能——她不是反复出现的角色，她只在这一个瞬间代表"被群体压力压回椅子的人"。

**是否必须修改**：否。如果实习记者是后续不再登场的单次人物，此处叙事者的全知越过一人的信息边界是可接受的。

### AI-13：第5章——陆沉全部心理路径被叙事者铺设为完整论证

**文件**：第5章，第85-89行
**等级**：🟡 建议修改

**原文**：
> "他应该写什么？'该设计可能导致全市居民做同样的梦并在必要时集体沉默看着一个人从二十七楼跳下去'——格式不合格。系统不接受这种理由。系统只让你停止如果你能解释为什么。"
>
> "他点了'沿用'。发送。"

**判断理由**：

从"他应该写什么？"到"他点了'沿用'"之间，叙事者走完了陆沉的完整心理路径：设想拒绝的理由→意识到理由不可说→理解系统只接受可说的理由→决定沿用。每一步都铺设在读者面前。

但"他点了'沿用'"三个字本是这一章最黑暗的动作之一——同意自己的杀人工具继续投放。如果在"他点了'沿用'。发送。"之前删去一步心理推演（如删去"系统只让你停止如果你能解释为什么"），读者在读到"沿用"时的冲击会更强——因为读者需要自己去想"他为什么不停"。

属于检查项12"所有信息都被解释清楚"。

**是否必须修改**：否。当前版本通过"系统不接受这种理由"建立的主题是有效的。但最小改动可以让这个时刻更锋利。

**最小修改方向**：

```
他应该写什么？"该设计可能导致全市居民做同样的梦并在必要时集体沉默看着一个人从二十七楼跳下去"——格式不合格。

他点了"沿用"。发送。
```

### AI-14：第1章——三组"没有人"排比（有效使用）

**文件**：第1章，第113行
**等级**：🟢 可保留

**原文**：
> "没有人起身。没有人叫他的名字。没有人说'等一下'。"

**判断理由**：

三句"没有人"排比——属于检查项6。但这是 `target-style.md` 中描述的"群体场景用多个个体行为代替抽象概括"的标准样本。排比的三个动作（起身/叫名字/说等一下）是递进的：起身是最低的干预、叫名字需要语言介入、说等一下是在他走到栏杆前最后的挽回机会。三次否定同时也是三次沉默升级。

不属于模式化排比。可保留。

### AI-15：第1章——三组"隔着"排比与三组"有人/没有人"句首重复

**文件**：第1章，第119行和第125行
**等级**：🟡 建议修改

**原文**：

第119行：
> "隔着屏幕，隔着距离，隔着'我只是在场而已'的说辞。"

第125行：
> "有人打电话叫司机把车开到门口。有人拉着同行的人往外走，挽住手臂，低声说了句什么。没有人回头看露台。"

**判断理由**：

两个三连排比在六行内先后出现（L119→L125）。各自单独看都是有效结构：L119的"隔着"将逃避层次化，L125的"有人...有人...没有人"将散场的机械感呈现为行为链条。但两者间距过近——读者刚在L119经历了一次三连排比，L125立刻再给一次——排比的修辞力因连续使用而被摊薄。

属于 `target-style.md` 中"连续段落不堆叠比喻"的平行原则——修辞工具堆叠同理。

**是否必须修改**：否。但建议二选一：保留L113"没有人...没有人...没有人"和L119"隔着...隔着...隔着"中的一组（推荐保留L113，它有力得多），将L119的"隔着"缩短为两段或改成普通叙事句。L125的"有人...有人...没有人"保留——它在叙事上不可替代（是晚宴散场的收束）。

### 总体评估

第1-5章在肢体动作的具体性（检查项7、8）和人物语言差异（检查项3、4）上表现良好。"心头一紧""呼吸一滞""眸光微动"等AI万能身体反应未出现。人物对话保持了自然断裂和口语感。

**主要结构问题是两个**：
1. **旁白替读者解读**——叙事者在动作或观察已经到位后追加社会评论/心理总结。发生在第1章服务员微笑、第4章曹老板段落、第5章系统段落。
2. **"不是……是……"的过度使用**——在陆沉视角中是有效签名，但在叙事者描写和非陆沉人物视角中也开始渗透。

**节奏问题是第4章126-143行连续六段固定的"动作→结论"模式**，在一口气读完时会感到结论密度过高、呼吸空间不足。
