# 第3章《种子》场景C：空白海报

> 版本：V1重构初稿  
> 视角：陆沉  
> 场景功能：把公祭现场的共同注视转译成一个公共视觉素材，完成上传与撤回。  
> 结构限制：压缩设计软件操作，不把外包审核上升为主题说明，只写陆沉的选择和误判。

当晚，陆沉回到家，没有开灯。

他把电脑放在客厅地板上。屏幕亮起来，桌面上只有一个设计软件和一杯放凉的水。

第一个版本是人群剪影。很多黑色的人重叠在一起，肩膀和头部挤成一块，像压缩过度的照片。他看了几秒，选中，删除。

第二个版本只有一个人。脸画得太清楚，眉毛、鼻梁和嘴角都在，像一张通缉令。他删除了脸，又觉得剩下的身体没有意义。

第三个版本是一面镜子。镜面是白的，边框很窄，什么都没有。陆沉把它放到投影图里看了一会儿，关掉了文件。

第四个版本是四个人背对着一块空白的屏幕。它看起来像离开，不像注视。陆沉把文件保存下来，没有再打开。

凌晨四点，他画完第五个。

五个人物剪影并排站着。工人、学生、医生、老人，还有第五个。第五个的肩线、衣服褶皱和其他人没有区别，头部却留着一块完整的空白。

不是撕掉，也不是涂黑。

那里从一开始就没有五官。

陆沉在图下输入过三句话。

你们在看什么？

谁看见了？

最后都删掉了。

他留下：

你看见了吗？

这句话没有指向任何一个人。也没有告诉看见的人应该做什么。陆沉看着它，觉得这样就够了。

他把文件上传到城市文化基金会的共享项目后台，选择了“城市面孔”系列。

提交页面要求填写的内容很少：文件格式、分辨率、颜色模式、投放尺寸。没有一栏问这张图想让谁看见，也没有一栏问第五个人为什么没有脸。

第二天醒来时，审核结果已经通过。

陆沉坐在床边看了一会儿通知。他原本以为文件会被退回，甚至已经想好了一个不必解释的理由。现在页面上只有一个按钮：撤回。

他点了下去。

确认框跳出来：是否撤回第五版素材？

他又点了一次。

页面刷新后，状态变成：已撤回。

陆沉关掉电脑，把手机扣在桌面上。

他以为自己只是把一张不合适的海报收了回来。
