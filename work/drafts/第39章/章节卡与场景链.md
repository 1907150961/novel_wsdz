# 第39章《慢的办法》章节卡与场景链

## 章节卡

- **章节核心命题**：不用人群的办法也能改变现实，但只能一个一个人地改，而且改不掉已经发生的部分。
- **视角人物**：秦小满（S1/S3/S5）、乔安（S2）、陆沉（S4）
- **核心人物的本章目标**：秦小满——让想退出和想撤回的人有路可走，不替他们走；乔安——把报道要回来；陆沉——核算这套办法到底有没有用。
- **主要阻力**：绝大多数人不回应；已出去的内容收不回来；林昭把她的方法定性为"把受害者变成无名统计对象"。
- **读者进入本章最关心的问题**：秦小满的慢办法到底行不行？过客不回话之后两人还剩什么？
- **本章给予读者的实际回报**：慢办法真实生效——撤回、退出、报道恢复；同时看清它的价码——旧攻击原样挂着，删不掉。
- **本章结束后的状态变化**：林昭组织第一次公开分裂，三名见证代表退出，代表权垄断被打破；"十七岁女生已自杀"的错误材料进入秦小满视野。
- **章末牵引类型**：新问题（新材料未核验：是真是假？她收不收？）——与第37章（反问悬置）、第38章（私人瞬间）不重复。
- **预计场景数**：5；字数分配：S1约1500 / S2约1500 / S3约1700 / S4约1600 / S5约1700，合计约8000—8300。

## 场景链

### S1 秦小满·路径（约1500字）

- 时间：一月初，晚十点后（她每天留给档案的那一小时）；地点：写字台。
- 表层目标：把撤回、更正、申请删除写成具体路径，逐一私信发出。隐藏目标：证明她的办法不是没用。
- 阻力：四十余条私信，多数无回音；有人回"都过去了"；有人问"你是谁"。
- 开场状态：反问悬置，她不等；从档案抽出三张名单（公开留过句子的投诉者／转载过横幅的账号／七名见证代表）。
- 核心行动：逐条写路径、逐条发送，不发群、不@、不催；周启回信撤回并自认"当时连全文都没读完"，何工不撤（自便）；见证代表康宁问"怎么退出"。
- 场景转折：第一个人真的照着路径走完了撤回——慢办法第一次落在一具体的人身上。
- 结束状态：三条路径发出；康宁拿到退出步骤，附秦小满的诚实边界"退出之后，你发过的发言还在，这个我改不了"。
- 不能说出的内容：她不知道过客会不会拿这些结果做什么。
- 与上章因果：反问无回音→她把等待换成行动。
- 对下场景后果：撤回记录成为乔安申诉新证据。
- 预计字数：1500。

### S2 乔安·恢复（约1500字）

- 时间：数日后，周五下午；地点：报社工位。
- 表层目标：提交第三稿申诉，把页面要回来。隐藏目标：确认"等"这条路走不走得通。
- 阻力：老郑的务实提醒；恢复之后攻击仍在。
- 开场状态：申诉材料齐备——撤回记录（去标识化）+四轮时间轴+操作说明公开存在的事实。
- 核心行动：申诉只列结构不讲故事；平台复核通过，页面恢复；她刷新页面看评论——置顶还是那条旧攻击，点赞停在两个月前。
- 场景转折：恢复的页面像一间重新开门的空店——门开了，人没回来。
- 结束状态：报道恢复，账号功能随复核一并恢复；旧攻击和转载原样存在；她想过把《那晚》一起发，最终合上文档。
- 不能说出的内容：她不知道秦小满在背后做了多少条私信。
- 与上章因果：撤回记录让申诉成立。
- 对下场景后果：报道恢复成为组内分裂的引信之一。
- 预计字数：1500。

### S3 秦小满·分裂（约1700字）

- 时间：再数日后，周末；地点：学校晚自习后/宿舍走廊。
- 表层目标：观察组内变化，继续给请求者发路径。隐藏目标：不接林昭递来的论战。
- 阻力：林昭把她的方法公开定性为"把受害者重新变成无名统计对象"。
- 开场状态：撤回增多，组内气氛变了。
- 核心行动：三名见证代表先后辞职；林昭发长帖——没有共同的声音，个体就会被淹没（他高中投稿无人回应的逻辑第一次被组员复述）；有人反驳"退出权不是统计问题"；第一次公开分裂。
- 场景转折：康宁在分裂帖下正式退出，贴一句"我退出，因为我发现自己替别人说得太顺口了"。
- 结束状态：林昭不删帖不回应退出者，按"公共记录"口径保留一切；秦小满未发一个字，只把退出路径逐条发给私信请求者。
- 不能说出的内容：她对"统计对象"的指控有一半认——她的三栏确实是把人拆开了看的；她认一半，不认结论。
- 与上章因果：报道恢复+退出潮逼出组织路线之争。
- 对下场景后果：陆沉以过客身份看到全部结果。
- 预计字数：1700。

### S4 陆沉·核算（约1600字）

- 时间：同期某夜；地点：公寓。
- 表层目标：核验秦小满发来的去标识化结果。隐藏目标：给这套办法找一个归类。
- 阻力：他所有现成工具都把这类干预标为"无效"；他脑子里的三套快方案全部违反三条禁令。
- 开场状态：信原件在随身内袋；反问仍悬置；过客收到结果数据。
- 核心行动：核算撤回与退出的传播量——效率低到旧模型会归为无效，但伤害在减少，且没有产生新伤害；他的方法每赢一次都要制造新围观，她的方法没有围观所以没有新目标、没有新误伤。他回复"撤回时间戳核过了，对得上"——只回事，不回问。
- 场景转折：他发现自己不是"不能"更快，是"不该"。
- 结束状态：把"低传播纠错"第一次记入模型；新文件命名时打了"慢的办法"又删掉，改成日期。
- 不能说出的内容：他认了反问里"一直"两个字（不写破，只写动作）。
- 与上章因果：秦小满的结果数据经匿名通道到达。
- 对下场景后果：两人在规则内继续交换，为第40章"暂缓行动"铺垫。
- 预计字数：1600。

### S5 秦小满·代价与新材料（约1700字）

- 时间：又数日，期末考完；地点：写字台。
- 表层目标：回应康宁退出后的翻旧账。隐藏目标：确认自己愿意承受低效率。
- 阻力：转载删不掉；有一条快路一直在——发一条动态就能让所有人看见她的方法赢了。
- 开场状态：康宁退出后被翻旧账（"当初挂横幅也有你"）。
- 核心行动：她把申请删除路径再发一遍，附"能删多少删多少，删不掉的我记着"；她起草过一条动态（一夜就能……），写完删掉，遵守规则二第五条；康宁发来新材料："我现在不在组里了。这条你看要不要收进档案。"附图——"十七岁女生因同学造谣，已经自杀。"
- 场景转折：新材料没有名字、没有时间、没有地点；她手指停在"待核"上——真材实料的话，这就是下一个横幅；速度就回来了。
- 结束状态：屏幕停在那行字上，不解答。
- 不能说出的内容：材料真假（留第40章）。
- 与上章因果：退出者把组内流通材料带到她面前。
- 对下场景后果：材料将同时进入三处（第40章）。
- 预计字数：1700。

## 结构检查

- 每场景均有状态变化：S1路径发出+首例撤回；S2报道恢复；S3组织分裂+三名代表退出；S4模型新增慢速纠错+回事不回问；S5翻账应对+新材料入场。
- 因果链：S1撤回→S2申诉成立→S3分裂→S4核算→S5钩子；无"然后又发生"。
- 信息附着：撤回数据附着在周启的自认与方女士的后续上；林昭指责附着在分裂帖的论战上。
- 章末钩子类型（新问题）与最近三章（反问悬置／门痕意象收束／空心删除核验）不重复。
- 无预写未来：沈佳宜姓名、生死、医疗记录一律不出现。
- 场景准入：五个场景删除任何一个都会断因果。
