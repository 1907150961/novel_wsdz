## 二、12项诊断

---

### 诊断1：情节过度工整和可预测

**评级**：🟡 中风险

提纲的五幕结构清晰到可见骨架：序章（悬念）→ 觉醒（建立能力）→ 神话（案件+升级）→ 反击（侦探逼近）→ 越界（道德崩溃）→ 收网（陷阱+法庭）。每一幕的幕末小结都以格式化清单总结推进内容。

更值得警惕的是案件选择本身的递进过于"教科书式"：

```
秦越（确定的恶人）→ 丁辰（不知悔改的恶人）→ 造谣者（灰色地带的恶人）→ 曹立文（被误判的无辜者）→ 郑泽楷（被资本利用的正直者）
```

这条线的递进逻辑透明到读者可以在第3案（造谣者）时就预判到"下一个目标会是看起来有罪但实际无辜的人"。**故事不是在展开，而是在执行一份道德难度递增表。**

陆沉在第24章面对曹立文之死时的自我辩护结构也过于工整：①真正错的是刺他的人 ②任何人都认为他有罪 ③我只放大合理怀疑 ④如果法医早发现——这是一份标准的"认知失调的四个阶段"心理学教材示例，不像一个正在崩溃的人的真实思维。

**建议**：在曹立文案之前（或替代它），增加一个陆沉无法用他的四步逻辑消化的意外：不是"目标无辜"而是"目标的反击方式超出预期"。比如目标面对舆论围攻时采取的行为完全不在陆沉的模型预期之内——自杀未遂后的公开对话、法律反诉、或反过来成为网络英雄——让陆沉的"手术刀"比喻被现实砸碎，而非被一纸体检报告推翻。

### 诊断2：每个事件都只服务于主线

**评级**：🔴 高风险

提纲中几乎每一个事件都最终收束到陆沉的道德轨迹或周砚的调查进度上。检查配角线：

- **乔安**：她的调查→引出对峙→引出抉择→引出送匿名材料。每一步都服务于"让警方获得关键信息"的主线需求。她的独立生活（作为记者的其他报道、个人关系、职业压力）在提纲中为零。
- **夏明栀**：提纲中给她安排了一段"关于正义的独白"，但这句话作为独立事件没有自己的生命——她只是在对主线发表评论。她的从警十二年经历中，除了周砚送的烟盒外没有其他痕迹进入故事。
- **周砚**：他拒绝屈从民意的背景故事完全为主线的"不合群→免疫潜潮"设定服务。他不吃面、手写倾斜——这些习惯只被陈述但从未给他的调查带来过麻烦（或意外的帮助）。
- **林昭**：最接近独立弧线的配角——他的行动有自己的因果链（崇拜→模仿→失败→入狱→释放后延续）。但他在第30章的失败（雇人围攻暴露）是一个在功能上向陆沉证明"没有我你什么都不是"的情节装置——服务陆沉而非林昭。

属于 `structural-problems.md` 中的"Filler arcs risk"的反面——不是填充，而是每一件事都太有用。**故事需要一些"无用"的瞬间：** 乔安在追查中偶然看到一条与案件无关但让她难受的新闻；夏明栀用了一个不能被写进主线的手段解决了一个与主线无关的纠纷；周砚因为他的怪癖错过了某趟公交从而迟到了半小时——这些"浪费"让世界比情节大。

### 诊断3：配角拥有独立于主角的目标吗

**评级**：🟡 中风险

| 角色 | 独立目标 | 是否独立于陆沉 |
|------|---------|-------------|
| 乔安 | 完成网络暴力深度报道 | ⚠️ 半独立——她的报道对象恰好是陆沉的案件 |
| 夏明栀 | 破案/维护程序正义 | ❌ 完全依附于主线 |
| 周砚 | 解开符号传播之谜 | ⚠️ 他的智力快感驱动他，但这个谜题恰好是陆沉 |
| 林昭 | 成为"审判者" | ✅ 在主线外部有一个独立驱动力（被看见的渴望） |

最薄弱的是**夏明栀**。提纲给她安排了一段对"程序是否能追上新形态犯罪"的独白——这是对主线主题的复读，不是她自己的欲望。如果她有：一个即将上中学的孩子（与秦小满的遭遇产生共鸣但不方便说出来）；一桩未被解决的旧案让她对本案件产生了不合理的紧迫感；或者她对周砚的信任正在被她上司质疑——这些不会改变主线，但会让她在主线中的每个决定（延期结案/相信周砚的梦境理论）不是"因为她应该这样做"而是"因为她是这样的人"。

### 诊断4：人物选择总是最有效率的选择

**评级**：🔴 高风险

陆沉的选择效率令人不安：

- Ch4提纲：他做了一个实验，精准地测试了能力，然后精准地说服自己"只是关店没人受伤"。
- Ch9提纲：他选择丁辰，因为"不知悔改最容易被舆论放大"——这是舆情分析师的理性选择，不是被母亲之死驱动的人的选择。
- Ch18提纲：他看到方睿陷阱，"一眼认出"并反向追踪——一个警方的精心陷阱在他面前如同透明。
- Ch32提纲：他看到韩树陷阱，知道是陷阱但"不得不上"——同时用三个符号规避追踪，保持最高效率。

这种效率让陆沉更像一个"完美棋手"而非一个被创伤驱动的人。**他从来不犯情感错误。** 他的每一次越界都保留了完整的自我辩护结构。唯一一次接近失控的是第30章林昭失败后的冲击——但他随后的反应是"在深夜打开新的符号设计文件"。

提纲需要至少一个**陆沉因为情感冲动（而非理性计算）而做出低效选择**的时刻。比如：他袭击了一个并非最优目标的人，只是因为那个人在网络上说了一句和他十四年前听到的侮辱母亲的话一模一样的话。这个选择在策略上是愚蠢的（会暴露他），但在人物上是真实的。

### 诊断5：反转依赖隐瞒信息，而非人物行动

**评级**：🟡 中风险

检查七个关键反转的信息来源：

| 反转 | 信息释放方式 | 是否依赖隐瞒 |
|------|------------|------------|
| 反转一（无人可定罪） | 机制本身的性质，Ch1已呈现 | ✅ 行动驱动 |
| 反转二（曹立文无辜） | 体检报告作为外部信息出现 | ⚠️ 依赖信息 |
| 反转三（周砚不合群=免疫） | 周砚的背景故事被揭示 | ⚠️ 依赖信息 |
| 反转四（现实证据定罪） | 陆沉的电脑日志被搜出 | ✅ 行动驱动（警方搜查是行动） |
| 反转五（信徒仍在） | 林昭延续行为 | ✅ 行动驱动 |
| 反转六（资本利用） | 乔安发现合同记录 | ⚠️ 依赖信息 |
| 反转七（林昭=缩影） | 林昭的整个弧线 | ✅ 行动驱动 |

曹立文案（反转二）和资本利用案（反转六）都依赖角色在某个时间点恰好发现了一份文件（体检报告/合作记录）。这两处如果改为：曹立文的无辜不是来自"恰好发现的报告"而是来自**陆沉自己的能力失效**——他发动能力后，公众对曹立文的愤怒异常地没有聚集——因为曹立文真的在小区里常年做义诊，他的邻居们自发在网上为他辩护。能力撞上了"真实的善"。这个意外让陆沉第一次意识到：不是所有人都会被舆论操控。而资本利用（反转六）如果在郑泽楷案之前就通过陆沉的数据分析中的异常信号来逐步呈现（而非一次性揭露），读者可以和陆沉同步发现"有人在利用我的能力"——比"乔安找到了合同"更有机。

### 诊断6：人物弧光过早确定终点

**评级**：🟡 中风险

陆沉的轨迹从头到尾是单向下坠：正义愤怒→能力觉醒→道德自辩→第一次杀无辜→被利用→无法停止→被捕→判刑。

这条弧线的问题是：**从第四幕（Ch24）开始，终点（被捕）就完全可见了。** 读者有13章的时间来等待一个已知的结果。

提纲中唯一能改变终点预期的变量是乔安的"给一次机会离开"（Ch34），但陆沉拒绝了。这是对的——他不能接受——但拒绝本身也是读者可以预判的。如果乔安在Ch34给出的不是"离开"而是另一个选项——比如"我帮你把证据清理掉，但你帮我做一件事"——这个提议会迫使他做一个他无法用现有道德框架处理的选择，从而让"被捕"不再是唯一可见终点。

属于 `structural-problems.md` 中的"Stakes plateau"的变形——不是赌注停止升级，而是路径的可预见性让剩余章节失去了"不知接下来会怎样"的紧张感。

### 诊断7：冲突总在同一章内得到阶段性解决

**评级**：🟡 中风险

提纲多数章节的结构是：引入冲突→展开→阶段性解决→钩子。典型的案例章节（如Ch9、Ch12、Ch22-23）都是包含目标选择、符号设计、舆论发酵和结果（或阶段性结果）的完整小循环。

问题不在单章，而在**连续章节之间的张力被逐一消解**。Ch9（丁辰的目标确定与符号设计）→Ch10（丁辰死亡、陆沉建道德边界）——两章完成了一个闭合的叙事单元。然后Ch12（新案件）重新开启。

这导致第二幕（Ch10-16）读起来像七个独立短片，而非一条持续升级的压迫曲线。如果某些冲突跨越了章节边界——比如丁辰案的舆论在Ch10没有结束，而是延续到Ch11并与"审判者传说"的扩散交织——读者保持的不确定感会更强。

### 诊断8：重复的"调查—发现—反转—钩子"结构

**评级**：🔴 高风险

警方线（周砚与夏明栀）的节奏在提纲中形成了可预测的循环：

| 章节 | 结构 |
|------|------|
| Ch6 | 警方正式介入 → 发现海报来源 → 尾钩=陆沉是项目经理 |
| Ch17 | 整理梦境 → 画出传播地图 → 尾钩=锁定基金会项目 |
| Ch18 | 设计方睿陷阱 → 确认凶手会筛选 → 尾钩=陆沉反向追踪 |
| Ch29 | 梳理证据链 → 确认不够定罪 → 尾钩=设计终局陷阱 |
| Ch31 | 设计韩树陷阱 → 三人协作 → 尾钩=等待 |

四次推进都遵循同一模式：**侦探获得一组数据 → 做出一个推断 → 章末留下一个调查方向。** Ch18和Ch31更是同构的——都是用虚构目标做陷阱。

打破这个循环需要的不是删除而是**打乱**——比如让Ch17的传播地图分析在陆沉的一个章节中被间接确认（他注意到基金会续约邮件恰好与梦境扩散的地理区域重合），从而把"侦探发现"和"陆沉感知"两条线做一次非对称的碰撞。或者让其中一个陷阱不是由周砚设计，而是陆沉给周砚设的——让侦探从设计者变成被设计者。

### 诊断9：角色为了推进情节而突然降智

**评级**：🟡 中风险

几处值得审视的降智时刻：

**陆沉在Ch27未能识别自己被资本利用**：他是舆情分析师，专业就是追踪舆论事件的源头和利益链。工厂公关公司是与舆情研究中心有合作关系的——合同关系、项目对接人、付款记录——理论上在陆沉的权限范围内可见（至少作为异常信号）。让他完全"不知道"直到乔安告诉他，降低了这个人物的专业可信度。

**检方在Ch36无法以杀人罪起诉**：从法律推理角度看，这个设置服务于"无人可定罪"的核心主题——是对的。但提纲安排了警方搜到陆沉对每个目标的"详细背景研究和可行性评估文档"——这些文档如果与死亡事件有明确的时间先后关系，在中国刑法体系下可能构成间接故意杀人（明知可能致人死亡而放任）。提纲需要更精确地界定这些文档的措辞（如果陆沉用的是"舆论惩罚""社会死亡"而非"物理死亡"，法律困境更有说服力）。

**周砚在Ch20被符号污染后夏明栀也"停顿了一下才回应"**：如果周砚的"不合群"属性让他免于被符号影响，那么夏明栀——作为与他有深度信任关系的人——被符号影响到对他产生本能疏远是合理的。但如果连她也受影响，则意味着**没有任何人能在符号面前保持独立判断**。这个设定会让"周砚不合群=免疫"的独特性被稀释——因为连最信任他的人都无法免疫，那免疫的标准就变成"必须绝对孤独"，这削弱了周砚作为一个社会存在物的可信度。

### 诊断10：提纲是否过度解释主题

**评级**：🔴 高风险

提纲在多个位置直接把主题写成了结论句：

- 核心概念行："一个人如果能操控社会的本能判断，他是在伸张正义，还是在谋杀自由意志？"
- 全书最后一句：周砚的内心独白明确说出"陆沉不是一个名字，它是一种欲望...凶器被没收了，但握凶器的那只手，长在每一个人心里。"
- 全书末问答："谁来审判审判者？""没有人。"
- 反转清单每一条都是一个主题陈述
- 每幕小结都在复读陆沉的道德状态变化

这些在**提纲文档**中出现是正常的——提纲需要用清晰语言告诉作者故事在做什么。但风险在于：它们同时也是**给写作 agent 的指令**。如果一个写作 agent 读到"核心问题贯穿全书：当法律不够快、不够狠、不够解恨时，谁来审判审判者？"，它可能会在每一章里找到机会让人物说出接近这句话的内容。

正文第1-7章中已经出现这类迹象：第5章"系统不是为了让好东西流传设计的"、第4章"曹老板活在一个灰色的夹层里，他的清白和罪名都不需要证据"——叙事者在替故事说出它想表达的主题，而非通过人物的困境来让读者自己抵达。

**建议**：提纲保留主题描述（对作者有用），但在传递给写作 agent 时附加一条规则："此提纲中的主题陈述是给作者的备注。正文中不得让人物直接说出这些句子。"

## 四、后续五章调整建议（第8-12章）

### 第8章：不再写"记忆（下）"

**原提纲**：母亲自杀当天、葬礼、邻居送花圈、回到现在看第二目标资料。

**问题**：正文Ch5-7已大量覆盖了死亡和葬礼内容。

**建议方向**：
- 时间跳进：陆沉在母亲死后的第一年。他如何选择了大学专业（传播学与社会心理学）。他的教授在课堂上讲"沉默的螺旋"理论时，全班只有陆沉一个人在笔记本角落反复写一个词。这个词不是"妈妈"——是"证据"。
- 这场闪回的落点是现在：陆沉在第5章结尾写的"谁"字——他意识到"不知道谁在加砝码符号"的状态，和他十五岁时"不知道谁在发帖污蔑母亲"的状态，是同一种失控。
- 章末：陆沉关闭"传播模型"文档。打开第二目标资料——这次不是因为正义，是因为他需要重新证明自己还能控制局面。丁辰是第一个被"我害怕失控"而非"我愤怒"驱动的目标。

### 第9章：丁辰案

**原提纲**：基本保留。但需调整开场——不是"陆沉已完成符号设计"，而是他在不安中推进。

**新增一层**：陆沉在监控丁辰案的舆论时，同时分屏监控着一个单独的搜索——"砝码"、"曹"。丁辰案的符号（无脸少年）正在按他的计划扩散，但"砝码"关键词的曲线也在——每三天波动一次，像一个他不认识的人在他的房子里走路。

### 第10章：丁辰死亡 + 陆沉第一个裂缝

**原提纲**：基本保留。丁辰的七十二小时和死亡直播是有效内容。

**但需调整结尾**：原提纲陆沉在屏幕前建立道德边界（"他只对真正的恶人出手"）。这个自我辩护可以被保留，但需要在同一章的另一个瞬间暗示这个边界的脆弱——比如陆沉合上电脑后，发现自己在纸上无意识地画了一个砝码。他盯着那个砝码，然后撕了纸。

### 第11章：审判者传说（重写衔接）

**原提纲**：陆沉的"辟谣"反助信仰 + 发现能力随信仰增强。

**正文已有变化**：正文Ch5已建立"794人接龙""它在我窗子外面"的无脸梦扩散级别。Ch11如果重复"人们开始相信审判者存在"，会和Ch5形成信息降级。

**建议方向**：Ch11不应是"传说开始形成"而是"传说开始分化"。网络上出现两个对立的解读：一群人相信审判者是英雄，另一群人开始恐惧"下一个可能是我"。陆沉发现——恐惧的传播速度比崇拜更快。但恐惧不会增加他的能力感应力。只有"信仰"（相信他在做正确的事）才会。这意味着：如果公众从崇拜转向恐惧，他的能力会萎缩。这是他第一次面临一个无法用"设计更好的符号"来解决的问题——人们的反应方向不在他的控制范围内。

### 第12章：第三案（造谣者）

**原提纲**：基本保留。但需增加一个与第5章砝码/曹线的交汇。

**建议**：在陆沉决定对造谣者出手的瞬间，他犹豫了——不是因为道德，而是因为他在舆情数据中看到了一个让他不安的信号：关于造谣者的舆论中，已经出现了一个他从未设计的微型符号——一把剪刀的轮廓，只有指甲盖大小，嵌在一张论坛截图里。他在什么地方见过这把剪刀。他翻回去看曹老板的帖——不是同一把剪刀。但在砝码梦中出现的那个"曹"字旁边，如果仔细放大像素，有一个极淡的、剪刀状的压痕。

这不是林昭。林昭还没有登场。这是一条**提纲中不存在的新线**——但它是正文第5章"砝码/曹"悬念的必然延伸。
