# 需要避免的写法：kb/styles/avoid-patterns.md

> **提取来源**：`samples/rejected/` 两份样本 + 第1-7章评审记录
> **编制日期**：2026-07-13
> **使用方法**：写作和修订时逐条检查，确保不落入下列模式

---

## 一、提前替读者解释钩子（来源：rejected/01）

### 1.1 模式描述

在第一现场描写了一个有效细节后，立刻用叙事者的后见之明告诉读者"这个细节后来被某人反复研究/反复播放/成为关键证据"。

### 1.2 已出现的实例

```
那个画面后来被周砚从监控里截下来反复播放。每一次他都觉得那是一个字被咽回去的形状，但他说不出来是哪个字。
```
（第1章：服务员嘴角一动 → 叙事者立即宣告此细节将来会被反复播放。）

### 1.3 错误原因

- 读者失去了通过周砚的眼睛第一次发现这个细节的机会。
- "一个字被咽回去的形状"是主观解释——叙事者替读者完成了判断。
- 缩短了悬疑的生命周期：从"这是什么？"变成了"哦，这个以后要用"。

### 1.4 改写规则

第一现场只保留可观察动作。不预告其重要性。不提供主观解释。

```
服务员转身往后厨走，嘴角动了一下，又恢复原状。
// 到此为止。留给周砚去发现，留给读者去记住。
```

## 二、"事后拼出"的伪推演（来源：rejected/02）

### 2.1 模式描述

叙事者标明人物是"从多方信息中拼出"或"后来才知道"，但紧接着写出的细节（对话原话、微表情、具体动作）只有现场目击者才能获得。

### 2.2 已出现的实例

```
后来陆沉从多方信息中拼出了那天傍晚的完整画面。

三十多个人，在下午六点四十分左右出现在广平路东段。……一个穿格子衫的年轻男人站在最前面，手里攥着一张打印出来的论坛帖子截图。他没有递给曹老板。他只是拿在手里，像拿着一道没有写在纸上的问题。

"你这茶叶不对。"格子衫说。

曹老板愣了一下。然后笑了——那种笑不是觉得好笑，是想用笑来证明没什么大事。
```
（第4章：数据推断→全知视角。帖子的截图内容、格子衫的对话原话、曹老板的笑容类型——均无法从论坛数据或舆情曲线中推断。）

### 2.3 错误原因

- "拼出"一词建立了信息边界，后面立刻越过边界。
- 读者被迫在"陆沉很聪明，能推断一切"和"这是叙事者作弊"之间做出选择——通常是后者。

### 2.4 改写规则

"事后拼出"只能写数据可支持的推断：
- 人数范围（从定位数据密度推算）
- 持续时间（从第一条和最后一条相关帖子的时间差推算）
- 地理聚集（从IP/基站数据的空间分布推算）

不能写：
- 参与者的具体原话
- 任何人物的微表情
- 独自一人时的行为
- 未在任何公开帖或数据中出现的对话

如果需要这些细节，要么（A）安排陆沉在场，要么（B）安排一个在现场的目击者在论坛发帖转述，陆沉从中读取。

## 三、同章内相对时间的双重口径（来源：rejected/02）

### 3.1 模式描述

在同一章内对同一事件使用两个不同基准的时间表述，且两者不兼容。

### 3.2 已出现的实例

```
第八天，那家店关门了。
```
（第4章第89行）

```
第二天曹老板贴了停业通知。第三天回了老家。
```
（第4章第113行）

如果"第二天"和"第三天"是相对于围堵日（第四天傍晚），则围堵(D4)→贴停业(D5)→回老家(D6)。但"第八天关门"与此矛盾——要么"D5关门"、要么"回老家后才关门(D6)"、"第八天"无法与两者兼容。

### 3.3 错误原因

- 一个事件出现了三个可选时间点（D5/D6/D8），读者无法确定应该信任哪一个。
- 这种矛盾属于低级错误——任何时间线校对都会在第一遍检查中发现。

### 3.4 改写规则

- 同一事件只使用一个相对时间锚点。
- 选择锚点后，全文其他所有涉及此事件的日期必须从该锚点推算并保持一致。
- 论坛帖中涉及的日期、警察调查进度表、其他人物对此事件的提及——全部需要重新校对。

## 四、AI 默认的"细腻生动有感染力"式解释（来源：评审记录）

### 4.1 模式描述

在描写已经到位后，叙事者忍不住再追加一句解释性的总结，把读者已经看到的东西用抽象评价再包装一遍。

### 4.2 常见实例模板

```
× 房间里一片寂静。那种寂静不是安静，是有什么东西正在酝酿的寂静。
× 她的眼神里有一种说不清的东西，混合了悲伤和愤怒。
× 那个瞬间，他明白了一切。一切都有了答案。
× 那种感觉无法用语言形容。但如果你经历过，你就会懂。
```

### 4.3 错误原因

- 第一条"安静不是安静，是有什么东西酝酿的安静"——叙事者替读者解读了自己的描写。
- "说不清的东西""无法用语言形容"——叙事者放弃了用语言描写的职责。
- "他明白了一切"——跳过了推理过程，让读者无法跟随。
- 所有这些都属于"作者不相信读者能读出来，所以要加一句标注"。

### 4.4 规则

如果描写已经到位，删除后面所有的解释性总结句。描写和解释只保留其一，且优先保留描写。

## 五、"不是……是……"句式的过度使用

### 5.1 模式描述

"不是……是……"/"不是因为……是因为……"在陆沉视角中是有效的人物声音标记。但当它出现在叙事者描述（非陆沉视角）、出现在其他人物视角中、或者同一章内出现5次以上时，便从人物特征退化为可预测的作者手势。

### 5.2 已出现的过度实例（第5-6章评审记录指出）

- "不是笑——嘴唇只是向一侧牵了不到一厘米"（叙事者，非陆沉视角）
- "不是恐惧——或者不全是"（陆沉视角，有效）
- "不是认人。是评估。"（夏明栀视角——不符合她的语言习惯）
- "不是性格变，是体积变。"（叙事者，可用于闪回中的陆沉观察）
- "不是坚强。是他发现哭和不哭都不影响任何人。"（陆沉视角，有效）

### 5.3 规则

- 每章"不是……是……"总量不超过4次。
- 仅限陆沉视角段落使用。
- 叙事者描写、周砚场景、夏明栀场景均使用其他句式。

## 六、接水/拧瓶盖/擦键盘的惯性填充

### 6.1 模式描述

陆沉在情感紧张时反复做以下动作：接水、喝一半、拧瓶盖、擦手、关电脑、站起来、坐下。这些动作在第1-4章建立了他的人物质感，但到了第5-7章已成为机械重复。

### 6.2 已出现的重复统计

| 动作 | 出现章节 |
|------|---------|
| 接水/烧水 | 第2章、第4章（2次）、第5章 |
| 拧瓶盖 | 第4章 |
| 水太烫端着不喝 | 第2章 |
| 关掉电脑/合上电脑 | 第2章、第3章、第4章、第5章 |
| 站起来又坐下/靠着 | 第2章、第3章、第4章 |

### 6.3 规则

- 接水系列动作：每章最多1次。
- 如果连续两章都出现同一动作，第三至四章必须换用全新的物理替位动作。
- 新动作应从场景的即时环境中产生（正在做的事、手中的物件、当前位置），而非从动作模板库中调用。

## 七、微表情的过度解读

### 7.1 模式描述

人物观察他人时，逐帧解读面部肌肉的移动幅度和含义（"嘴角牵了不到一厘米""停了大概零点几秒"），并给出精确的心理学术标签。

### 7.2 已出现的实例

```
但他看你的那一下——他停了大概零点几秒。不是认人。是评估。他在想'这个人是谁，他在看什么，他为什么站在夏明栀后面偏后半个身位'。
```
（第6章：夏明栀解读陆沉的零点几秒视线停留。她作为刑警可以这样分析，但不宜在同一章内由陆沉、周砚、夏明栀三方轮流做同类型解读。）

### 7.3 规则

- 每个观察场景（如第6章问话后的复盘），微表情解读最多由一个人完成。
- "零点几秒"式的数字精度每章最多1次。
- 观察→解读→验证这一链条应该有一个外部证据来闭合（如夏明栀提到"我在镜子里看的"），否则观察只是观察者的自我确认。

## 八、章末使用同一个钩子策略

### 8.1 模式描述

连续章节的尾钩使用同一结构（"他打开了一个新的设计文件。光标停在白色画布中央。一闪。一闪。"→"他重新打开电脑。打开城市文化基金会的共享后台……光标在标题栏里闪。一闪。一闪。一闪。"）。

### 8.2 已出现的实例

- 第3章章末："光标在标题栏里闪……一闪。一闪。一闪。"
- 第4章章末："光标停在白色画布中央……一闪。一闪。"
- 两次尾钩的视觉意象和动作逻辑几乎相同。

### 8.3 规则

- 同一视觉意象不作为连续两章的尾钩。
- 如果两章尾钩必须表达类似的"他在犹豫/在启动某个东西"，用不同的动作或物件来承载（如第5章用"他打了一个名字……打了四个字，删了三个。最后留在屏幕上的只有一个字：'谁。'"——突破了"光标闪"的模式）。

## 九、"后来他意识到/后来他明白"式的后见总结

### 9.1 模式描述

在描写了某个场景后，用"后来他意识到""他后来花了很长时间才明白""后来他做了×××，用的就是这天学到的"来为场景加贴一个主题标签。

### 9.2 需要区分的情况

**有效用法**（连接过去与现在的人物行为）：
```
他后来在舆情分析里反复使用的一种数据清洗逻辑，就是从这一天学的：噪音需要被删掉，不是因为噪音假，是因为噪音会拖慢判断速度。他删数据的时候脑子里划过一条很直的圆珠笔横线。
```
（第7章：过去的具体动作→现在的职业习惯→两者的因果是可见的。）

**无效用法**（单纯的总结性评价）：
```
× 他后来才明白，那个下午改变了一切。
× 他后来意识到，自己一直在重复母亲的错误。
```
如果"后来"后面的内容只是抽象评价而非可观察的行为链条，则删除。

### 9.3 规则

"后来"句式只用于连接两件可观察的事（过去的动作→现在的动作/习惯），不用于发表抽象的人生感悟。

## 十、人物之间用旁观者视角做互相确认

### 10.1 模式描述

A观察到B的某个细节→C再观察到同样的细节→三人轮流向读者确认"是的，这个细节很重要"。

### 10.2 已出现的实例（第6章评审记录指出）

面馆场景中：陆沉看周砚的零点几秒被夏明栀描述→周砚反推陆沉在评估两人角色→两人又共同确认陆沉用了镜子。同一个观察细节被三道工序处理，每一道都在告诉读者同一件事。

### 10.3 规则

同一观察细节，一个人物做发现和解读，另一个人物可以补充新信息（如"我在镜子里看的"），但不能再次从头解读。如果两个人物的解读内容重叠，只保留第一个版本。

---

## 十一、用一个短句单独成段做情感宣告

### 11.1 模式描述

在描写了情感场景后，用一个简短判断句单独成段收束：

```
× 那一刻，他崩溃了。
× 一切都变了。
× 他知道回不去了。
× 那是他最后一次见到她。
```

### 11.2 错误原因

短句的情感宣告替代了场景自身的收束力。读者不需要被告知"这一刻很重要"——场景本身应该能做到这件事。

### 11.3 规则

场景收束用具体动作或物件，不用情感评价句。
