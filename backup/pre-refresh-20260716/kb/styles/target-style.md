## 一、叙事视角与视角距离

### 1.1 视角类型

第三人称有限视角，贴附于当前场景的主要人物。同一章内允许多角色轮换（如第1章从秦越→夏明栀→周砚→陆沉），但每次切换以场景中断（`---`）为边界。

### 1.2 视角距离

叙事者紧贴人物的感官，但保留一层观察距离——叙事者可以描述人物"注意到"和"感到"，但不会用全知口吻宣告人物不知道的事实。例：

```
陆沉把两只手从键盘上移开。他意识到自己在抖。不是因为恐惧——或者不全是。是因为在"恐惧"下面还有一层他不认识的情绪。
```
（第5章：叙述跟着陆沉走，包括他对自己的不确定。）

**约束**：
- 叙事者不替人物下结论。人物不确定时，叙事者也保持不确定。
- 叙事者不跨入其他人物的大脑——周砚在想什么只能通过陆沉/夏明栀的观察（或周砚自己的场景）来推断。

## 二、句长与长短句变化

### 2.1 基础模式

| 类型 | 字数 | 用途 | 频率 |
|------|------|------|------|
| 极短句 | 2−8字 | 节拍控制、强调、坠落的瞬间 | 每200−300字1次 |
| 短句 | 10−25字 | 常规动作描写、对话标签 | 高频主体 |
| 长句 | 40−80字 | 累积观察、心理链条、场景氛围 | 每段1−2次 |

### 2.2 极短句的功能

用于中断前文的叙述节奏，制造停顿或加速坠落：

```
他很安全。

他开口了。

他停了下来。

二十七层。
```
（第1章：四个极短句分别在建立安全→推进动作→断裂→收束死亡。）

**约束**：极短句单独成段。连续不超过两次。不使用感叹号。

### 2.3 长句的结构

长句通过破折号（——）内嵌分句，形成观察链：

```
后排有一个人的手机在口袋里震了四次——他后来发现是外卖骑手在催他取餐，他点了一份麻辣香锅，送到公司前台了——但他没有伸手去拿。
```
（第1章：破折号中间夹入具体生活细节，打断严肃场景，制造荒诞反差。）

**约束**：长句内部最多两层嵌套（破折号内不再破折号）。长句后必须跟一个短句或段落断开，避免连续长句造成阅读疲劳。

## 三、段落节奏

### 3.1 段落长度分布

- **极短段**（1−2行）：场景切换、内心转折、单句强调
- **标准段**（3−6行）：一个观察单元或一个动作序列
- **长段**（8−15行）：累积的回忆、多步推理、或需要一口气读完的场景高潮

三者交错出现。同一长度连续不超过三段。

### 3.2 场景中断

场景之间使用 `---` 分隔。新场景的第一句话不承接上一场景的末尾，而是重新建立空间/时间/人物。

## 四、对话比例与对话形式

### 4.1 比例

对话占总字数约15−25%。长对话场景（如第6章阅览室问话、面馆分析）中，每2−3句对话必须插入一次动作描写，防止变成纯对话体。

### 4.2 对话标签

对话标签镶嵌在物理动作中，不使用独立一行的"他说/她说"：

```
"拿到了。"夏明栀从包里抽出一张纸。城市文化基金会"城市面孔"项目人员名单——四十三个人。她用手指在第五个名字上点了一下。
```
（第5章：标签（"夏明栀从包里抽出"）同时是场景动作，推进叙事。）

**约束**：
- 不使用"××说："开头的独立行（除非是极短的问答交锋）。
- 对话的标点挂在引号内，引号外紧跟动作或叙述，不设逗号断开再另起一行。

### 4.3 对话中的停顿

停顿用动作描写填充，不用省略号或多行空白：

```
"他整段话都没有问题。每一句单独摘出来都对。但他回答问题的方式——"

"怎么？"

"太快了。不是紧张的那种快。是提前准备好的那种快。"
```
（第6章：周砚的思考停顿用破折号切断，夏明栀接上，周砚再用三句话展开。）

## 五、人物心理呈现方式

### 5.1 核心原则

**先写动作和空间，再写心理判断。心理判断只下一次，不反复解释。**

```
父亲没有抬头。他夹了一根青菜放在碗里，没有吃。

"我没有怪你。我是觉得——"父亲说，"如果当初我不跟你说'别怕，咱们有理，坚持到底'——你是不是就早放弃了。"
```
（第7章：父亲的情绪完全由"夹菜不放""没有抬头""嚼了很长时间"三个动作承载。叙事者不做任何"他很愧疚"式的标注。）

### 5.2 "不是……是……"自我修正句

这是陆沉视角的标志性句式，用于表现他的自我审视与自我辩护：

```
不是因为恐惧——或者不全是。是因为在"恐惧"下面还有一层他不认识的情绪。
```

**约束**：
- 每章"不是……是……"/"不是因为……是因为……"最多出现3−4次。超过即为过度。
- 其他人物视角不使用此句式（这是陆沉专用）。

### 5.3 情绪命名的最小化

不直接写"他感到恐惧""她很愤怒""他崩溃了"。改为：

- 身体反应：手抖、出冷汗、站起来又坐下、反复拧瓶盖
- 动作缺失：没有接水、没有开灯、没有回信息
- 物件描写替代情绪：水杯太烫端着不喝、窗帘拉了一半、面已经凉了

## 六、动作与环境描写方式

### 6.1 环境建立

每个新场景的第一段落到一个具体物件上：

```
宴会厅里的水晶吊灯太亮了。
```
（第1章）

```
周砚住的地方不大。客厅的茶几上搁着一个泡面碗，碗底有一层凝固的红油。
```
（第2章）

```
老房子在城郊。门口有棵桂花树，地上铺了一层褐色的花瓣。
```
（第6章）

**规则**：环境通过物件建立（灯、碗、树），不使用全景式"这里是一个……"的空间描写。

### 6.2 动作链条

连续动作写成链条，用句号分段，节奏紧凑：

```
他把车停在路口，走路过去。那扇门上有两道划痕。他把手指放在旧的那道上，然后放到新的那道上。两道划痕相距不到两厘米。
```
（第6章：停→走→看→放→再放→测量，六个动作形成一条不可中断的链条。）

### 6.3 群体场景

写人群用多个具体个体行为代替抽象概括：

```
台下的人没有对视，没有交头接耳。他们只是保持安静。那种安静过于整齐了——整齐到坐在第六排靠走廊位置的一个中年男人打了个喷嚏，周围五个人同时转头看了他一眼，然后又同时转回去。
```
（第1章：先写群体沉默，再用一个人的喷嚏+五个人的同步转头来证明沉默是"整齐"的。）

## 七、比喻密度

### 7.1 类型

比喻全部来自场景中的日常物件：

| 比喻 | 来源域 | 原文 |
|------|--------|------|
| "像一串正在发烫的珠子" | 车灯 | 第1章 |
| "像一整块幕布上撕开的第一条缝" | 哭声 | 第3章 |
| "像水往低处流" | 人群围堵 | 第4章 |
| "像墙角的潮斑" | 眼泪 | 第7章 |
| "像一个你刚认识的词，在你嘴里转了一圈又回到辞典里" | 能力消退 | 第3章 |

**规则**：
- 不用文学典故、不用超现实意象、不用自然奇观作为喻体。
- 喻体必须在当前场景中可感知（车灯、水、幕布、潮斑、辞典）。
- 每千字约1−2个比喻，连续段落不堆叠。
- 不使用"仿佛""宛如""好似"——只用"像"。

### 7.2 禁止的比喻类型

- "像一只被困的野兽"（人物不必像动物）
- "像一幅油画"（场景不是艺术品）
- "像命运的齿轮"（禁止抽象概念做喻体）
- 任何"美得令人心碎""恐怖到令人窒息"式的效果预告

## 八、留白方式

### 8.1 叙事者不回答自己提出的问题

```
他最终找到了吗？

没有人知道。
```
（第1章：叙事者明知答案但拒绝给出，保持现场人物的信息边界。）

### 8.2 "不知道"作为叙事工具

关键角色在关键时刻说"不知道"——不是示弱，而是界定证据边界：

```
"我不知道。"周砚合上笔记本。"但如果这些梦不是从他们自己脑子里长出来的——那就值得查。"
```
（第1章：周砚承认不知道，紧接着给出行动方向。）

### 8.3 对话中咽回去的内容

```
"这种人要么是受过训练，要么是——"

"天生。"夏明栀把面碗端起来喝了一口汤。
```
（第6章：周砚的句子被夏明栀接住并完成。两人共享的判断不需要被展开解释。）

### 8.4 章末尾钩

章末尾钩类型：

| 类型 | 示例 | 出处 |
|------|------|------|
| 单动作收束 | "他翻过栏杆，坠入夜色。" | 第1章 |
| 重复三连 | "一闪。一闪。一闪。" | 第3章 |
| 悬而未决 | "这一次，他知道自己在画谁的脸。" | 第4章 |
| 单字收束 | "谁。" | 第5章 |
| 动作+意象 | "他踩过去了。" | 第6章 |

**规则**：章末不加作者旁白。不在尾钩中预告下一章内容。尾钩是场景内部的私人瞬间，不是面向读者的信号弹。

## 九、场景开头与结尾

### 9.1 章节开头

两种模式交替：

**模式A——时间标记文档**（用于大段时间跳跃后重新锚定读者）：
```
**【事发第三天·《城市晨报》】**

> "本报讯：前秦氏集团董事长秦越于三日前……"
```
（第2章）

**模式B——物件/动作直入**（用于同一时间线内的连续叙事）：
```
秦越死后的第二周，陆沉决定做一个实验。
```
（第4章）

```
陆沉梦见自己在母亲的葬礼上。
```
（第5章）

**规则**：连续不超过两章使用同一模式。

### 9.2 章节结尾

结尾回到当前场景中人物的私人感知，不扩展至群像或社会全景。不使用"而在这个城市的另一端……"式的视角跳跃。

## 十、各主要人物的语言差异

### 10.1 陆沉

- 自我修正句式（"不是……是……"）
- 将情感翻译为技术术语（"输入源""启动阈值""传播模型"）
- 物理替位动作：接水、拧瓶盖、删改文字、关掉不保存
- 内在独白偏长、偏分析

### 10.2 周砚

- 句子偏短，不解释自己的推理过程
- 提问多于陈述
- 动作：看窗外、合上笔记本、不吃只搅动碗里的面
- 不接情绪球——对方抛出情感语句时他沉默或转回事实层面
- 手写时"笔斜着拿，字迹向左倾斜"

### 10.3 夏明栀

- 在专业和私人语气之间切换快速
- 用具体物品承载判断（烟盒捏变形、筷子放下不吃、手机扣在桌上）
- 做决定时伴随物理动作（在材料封面写"退回调查"并签名）
- 偶尔用反问推进对话（"哪一句？""怎么？"）

### 10.4 苏婉清（闪回中）

- 语气平静，用日常动作包裹沉重内容
- 不直接表达痛苦，而是通过整理衣架、划掉名字、翻相册等动作
- 话语带有务实的哲学感（"我不怕失败。我怕的是有一天我不再愤怒了"）

### 10.5 对话中的权力关系

- 陆沉 vs 警方：陆沉话多但不给入口（完整实话藏关键信息）
- 周砚 vs 夏明栀：周砚提方向，夏明栀做判断并执行
- 苏婉清 vs 陆远舟：她陈述，他沉默

## 十一、章节开头的论坛帖/新闻引用规范

每章开头的引用材料（论坛帖、新闻、档案馆资料）遵循：
- 时间标记明确（"事发第×天""三个月前""十四年前"）
- 引用内容与正文之间用 `---` 分隔
- 论坛帖保留网络语言的真实感（错别字、短句、无标点），但不刻意堆砌网络流行语
- 新闻用正式报纸语体，与论坛帖形成语域对比
- 引用材料不超过三段；超过三段的材料应拆分到不同章节
