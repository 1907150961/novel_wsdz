# 抽象短句与内部黑话

**不作为目标风格**：不要用上一章内部术语（路径、边界、节点、缺口、模具、第一层待补）当叙述，也不要把判断叠成「A。A是B。B不能C」的连环短句。读者对不上纸上写了什么时，句子就是失败的。

## 正文样本

> 概率较高栏旁边仍写着一个字：待。无法确认比例那一行，纸边空着。她拿铅笔补了半句：人为什么点下去，这一栏里没有。
>
> 这句话她没有发给过客。过客拆的是路径，路径她认，可路径回答不了她要补的那一层。她翻到自己写过的“第一层待补”。当时她空着人名，空着是边界：挡的是交出去的文档，挡不住她自己去问。

出处：第36章初稿。作者判定：话太抽象，短句让人完全读不懂。

## 同类禁用（同一稿中的同病句子）

> 他没点秦小满的名字，点的是桥。笔尖停住。这个字从另一个方向伸过来，碰到她父亲，又停在没说破的地方。

> 顺序反了，人就会重新变成节点。

> 过客拆的是路径，路径她认，可路径回答不了她要补的那一层。

> 空着是边界：挡的是交出去的文档，挡不住她自己去问。

> 说明是模具，范本是让模具流传出去的土。

> 父罪不能替当前的纸作证。当前的纸要自己站。

> 凉在这句话太准。准的东西比恶的东西难拆。

> 干净是因为它把人收成密度。密度能画图。图能进报告。

## 问题

- 「路径」「边界」「第一层待补」「节点」「缺口」「模具」是写作备忘，不是读者此刻能看见的东西。
- 连环短句把同一个抽象词接龙（路径她认。路径回答不了），读起来像口令，不像人在想、在做事。
- 「点的是桥」「人变成节点」「模具往外长的土」把比喻压成半句话，读者要自己猜半天才知道发生了什么。
- 极短句只该用在真正要停的地方，不能用来讲推理。

## 改写规则

先写她手里的纸、栏里写了什么、缺的是哪一句。术语若必须出现，用前后的白话把它翻译出来。判断写成完整的句子，不要用冒号把两截抽象话焊在一起。

```
分析分了三栏。第一栏是已经能核对的事实：投诉分几轮出现，操作说明发在前面。这一栏她对过，时间对得上。第二栏写那些看起来像照着同一份说明填的投诉，旁边她自己留了一个字：待。第三栏问有多少人是刷到别人转发才动手的，过客只写了无法确认比例。这一行的纸边还空着。她拿铅笔补了半句：这些人当时为什么点投诉，这份分析里没有。

这句话她没有发给过客。过客把投诉怎么传开的写清楚了，先有说明，再有一轮一轮的提交，她认这个。可他没问过任何一个点下去的人。她翻到自己前几天写的备注：第一层待补。当时她故意空着人名，是怕把名字交出去。空着人名，不等于她自己不能去问。
```

对照：

| 禁用 | 改成 |
|------|------|
| 过客拆的是路径 | 过客把投诉怎么传开的写清楚了 |
| 空着是边界 | 当时她故意空着人名，是怕把名字交出去 |
| 点的是桥 | 说的是桥下面那些人 |
| 人就会重新变成节点 | 他就又会被算进同一批人里 |
| 范本是让模具流传出去的土 | 范本是让这种格式传出去的材料 |
| 父罪不能替当前的纸作证 | 父亲做过的事，不能拿来证明眼前这张纸是谁写的 |
| 把人收成密度 | 人被收成了数字 |
